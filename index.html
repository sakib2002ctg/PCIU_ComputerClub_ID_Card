How to Build This Exact ID Card in Canva

You can either click "Export PNGs" above to use these cards immediately, or follow this blueprint to recreate and customize them inside Canva with 100% editable layers.

1

Canvas Setup & Brand Colors

  • • Click Create a Design → Custom Size and set to 2.125 × 3.375 in (or 638 × 1013 px for vertical ID card).
  • • Add these exact Hex codes into your Canva Brand Kit or color picker:
Club Tech Green #58B947

2

Canva Elements Search Terms

Go to the Elements → Graphics / Shapes tab in Canva and search these exact keywords:

For Header & Bottom Shapes: "angled geometric banner", "modern corporate wave", "abstract blue polygon"
For Tech Watermarks: "circuit board lines minimal", "binary code pattern", "tech hexagon node" (set Transparency to 8%–12%)
For Member Photo Frame: "circle frame with border" or "rounded square frame" + add a subtle drop shadow.

Canva Native QR Code

Best Method • Editable Text & Photos 2 Pages (Front & Back)

1. Download Canva-Editable Layered PDF

Generates a multi-layer PDF where the background graphics, member photo, club logo, QR code, and every text line are separate layers.

  1. Step 1: Click the purple button below to download the layered PDF.
  2. Step 2: Open Canva.com → click Create a design → Import file (or drag & drop the PDF onto Canva).
  3. Step 3: Open the imported design in Canva — click any text box, photo, or logo to edit it!

2. Download Pure Vector SVGs (Front & Back)

Want to recolor individual ribbons or waves inside Canva, Illustrator, or Figma? Upload these .svg files into Canva → Uploads.
